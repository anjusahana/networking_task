Networking Concepts
What is an IP Address?

An IP Address is a unique number assigned to a device on a network so it can communicate with other devices.

What is a MAC Address?

A MAC Address is a unique hardware address assigned to a network adapter.

What is a Default Gateway?

A Default Gateway is the router that connects a local network to the internet.

What is DNS?

DNS converts website names like google.com into IP addresses.

Difference Between Public IP and Private IP

Public IP addresses are used on the internet and are globally unique, while private IP addresses are used inside local networks like home WiFi.
