 Objective

The purpose of this task is to understand basic cybersecurity concepts, evaluate the security of personal devices and online accounts, learn about common cyber threats, and develop awareness of safe digital practices.



 Activities Performed

Part A: Device Security Assessment

* Identified the operating system and OS version.
* Checked whether the system is updated.
* Verified antivirus installation.
* Verified firewall status.
* Collected screenshots as evidence.

Part B: Password Security Review

* Studied characteristics of strong passwords.
* Learned the importance of unique passwords.
* Understood Multi-Factor Authentication (MFA).
* Examined the risks of password reuse.
* Created a password policy with security best practices.

 Part C: Online Account Security Review

* Reviewed security settings of online accounts.
* Checked whether MFA was enabled.
* Verified the use of strong passwords.
* Confirmed the availability of recovery email settings.
* Prepared a security summary table.

 Part D: Cyber Threat Research

Researched and explained the following cyber threats:

* Phishing
* Malware
* Ransomware
* Social Engineering
* Data Breach

For each threat, the following were included:

* Definition
* Real-world example
* Prevention methods

 Part E: Cyber Security Awareness Poster

Created an awareness poster on a cybersecurity topic to promote safe online practices and digital security awareness.

 Part F: Security Reflection

* Identified cybersecurity risks in personal digital habits.
* Listed security improvements to implement.
* Reflected on the importance of cybersecurity in today's digital world.



 Skills Learned

* Device security assessment
* Password management and account protection
* Multi-Factor Authentication (MFA)
* Cyber threat identification
* Security awareness and safe internet practices
* Digital responsibility and risk management
