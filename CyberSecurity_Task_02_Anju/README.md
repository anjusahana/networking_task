Objective

The objective of this task is to understand the fundamental concepts of cybersecurity, including the CIA Triad, real-world cyber attacks, risk assessment, cyber threats, and security recommendations. The task also focuses on developing analytical and problem-solving skills by evaluating security risks and proposing measures to improve an organization's cybersecurity posture.

Activities Performed

Part A: Understanding the CIA Triad

Researched and explained:

* Confidentiality
* Integrity
* Availability

For each concept, the following were included:

* Definition
* Importance
* Real-world example
* Comparison table of the CIA Triad principles

Part B: Real-World Case Study

Studied the **WannaCry Ransomware Attack** and explained:

* What happened during the attack
* Which components of the CIA Triad were affected
* Impact of the attack
* Possible prevention methods

* Impact

* Description

Part E: Security Recommendations

Proposed security recommendations such as:

* Multi-Factor Authentication (MFA)
